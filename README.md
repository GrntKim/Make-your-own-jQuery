# Make-your-own-jQuery

A minimal jQuery 1.0 reimplementation, built lesson by lesson to study how
the original selector engine, DOM manipulation, and event system work
under the hood — without using Sizzle.

- `reference/jquery-1.0.js` — original jQuery 1.0 source (unmodified, for study)
- `src/script/myoj.js` — the reimplementation, built incrementally
- `src/index.html` — manual test cases for each lesson
